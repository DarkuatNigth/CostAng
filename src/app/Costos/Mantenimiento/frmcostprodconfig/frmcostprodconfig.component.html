Configuración de Costos Productivos

Mantenimiento de niveles, matriz de aplicación y cuentas contables. La matriz conserva reglas especiales aunque la vista principal sea True / False.
Lectura rápida: el switch encendido significa que el costo participa. Los códigos TAR, DEP, PRO, FIC, D y NA se mantienen como reglas especiales para no perder la semántica del archivo niveles de costeo. Doble clic sobre una celda para cambiar la regla exacta.

Cuentas contables configuradas

TIPOLIQ: {{ reglaTipoCodigo }} - {{ reglaTipoNombre }}

El switch de la matriz es una representación simple. Este valor es el que realmente se guarda en tb_configTipoLiquidacion_procesoCosto.
Al crear un TIPOLIQ nuevo, el front genera automáticamente todas sus celdas de matriz con regla NA. Luego se pueden activar con el switch o definir TAR/DEP/PRO/FIC/D.
El mantenimiento no pide al usuario seleccionar el proceso derivado. El backend resuelve LOG/REC/CLA/COD, DES/DSC/PEL/HID/COC, DEC/RET, BRI/IQF/TUN, CDF/CDV, CIF/CIV, MPE y COP con la misma lógica de la configuración actual. Las cuentas IQF siguen usando el mapa especializado existente.
